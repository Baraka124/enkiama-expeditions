# Serengeti Wildlife System

This page is the prototype for Enkiama's wildlife-destination family.

## Phase 1 — Ecosystem hub + governed data
- `data/serengeti.json` governs region, season, stay-length, access and operated-journey logic.
- The page treats Serengeti as a dynamic ecosystem rather than a single destination.

## Phase 2 — Region intelligence
- Southern plains
- Central Serengeti / Seronera
- Western Corridor / Grumeti
- Northern Serengeti / Mara River
- Eastern Serengeti
Each region carries strongest seasonal window, migration role, resident wildlife value, crowd profile, stay strategy and trade-offs.

## Phase 3 — Operated evidence
- July 2026 five-traveller journey
- Operated couple journey
- Hakuna Matata three-traveller journey
These show different roles Serengeti can play inside a wider Tanzania journey.

## Phase 4 — Serengeti composer
Inputs:
- travel period
- Serengeti nights
- wildlife priority
- tolerance for busy sightings

Outputs:
- first region direction
- stay strategy
- nearest alternative
- explicit migration caveat

## Wildlife-system publication discipline
- Never guarantee river crossings or exact herd position.
- Use seasonal windows as ecological guidance, not timetables.
- Distinguish Serengeti National Park from the wider Serengeti ecosystem and adjacent Ngorongoro Conservation Area.
- Do not imply migration is the only reason to visit.
- Avoid exact transfer-time claims without camp and route context.

## Reuse

Each page should retain its own editorial character while sharing governed decision fields where they are actually comparable.
